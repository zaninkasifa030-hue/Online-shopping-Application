# Online-shopping-Application
Project Title

Online Shopping Electronics Application
Platform Used

Wix

Project Description

The Online Shopping Electronics Application is a website where customers can buy electronic products online. Customers can view products, check prices, read product details, add items to the shopping cart, and place an order. The website is simple to use and helps customers shop from anywhere.


Problem Statement

Buying electronic products can take a lot of time because customers often have to visit different stores to compare prices and product features. Some stores may not have the product they need, while others do not provide enough information for customers to make a good decision.

This application solves these problems by giving users one place where they can search for electronics, compare products, read descriptions, add items to a shopping cart, and complete their purchase online.

The target users are students, workers, business owners, and anyone who wants to buy electronic products quickly and conveniently.

Challenges Faced

During the project, we experienced several challenges:

- Choosing a suitable color theme for an electronics shopping application.
- Organizing products into clear categories.
- Keeping all screens consistent.
- Connecting screens correctly in the Figma prototype.
- Designing a checkout process that is easy to follow.

These challenges were solved by revising the design, using Figma components, and testing the navigation between screens.



Conclusion

This project helped us understand the process of designing an online shopping application using Figma.

We learned how to identify user needs, create wireframes, design high-fidelity interfaces, and build an interactive prototype. The final design allows users to browse electronic products, add items to the shopping cart, complete purchases, and manage their orders through a simple and user-friendly interface.
